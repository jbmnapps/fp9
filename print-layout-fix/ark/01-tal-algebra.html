Tal og algebra

Regneregler
brøker · parenteser

Regnerækkefølge

Når en opgave har flere regnetegn, så regn i denne rækkefølge:

  1. Parenteser ( ) først
  2. Potens og rod (x², √)
  3. Gange og dividere (· og /)
  4. Plus og minus (+ og −)
Husk Inden for samme niveau: regn fra venstre mod højre.
Eksempel

3 + 4 · 2

Gang før plus:

= 3 + 8 = 11

Med parenteser:

(3 + 4) · 2 = 7 · 2 = 14

Parenteser: gange ind

Når der står et tal eller bogstav foran en parentes, så gang det ind på alt i parentesen:

a · (b + c) = a·b + a·c

Pas på Står der minus foran parentesen, vendes alle fortegn inde i den: −(a − b) = −a + b
Eksempel

3 · (x + 5) = 3x + 15

2 · (4 − a) = 8 − 2a

−(x − 3) = −x + 3

Brøker

Plus og minus: samme nævner: læg tæller sammen.

a/c + b/c = (a + b)/c

Forskellig nævner: gør dem ens (find fællesnævner).

Gange: tæller · tæller, nævner · nævner.

a/b · c/d = (a·c)/(b·d)

Dividere: gang med den omvendte.

a/b / c/d = a/b · d/c

Eksempel

Plus:

1/4 + 2/4 = 3/4

Forskellig nævner:

1/2 + 1/3 = 3/6 + 2/6 = 5/6

Gange:

2/3 · 4/5 = 8/15

Dividere:

3/4 / 1/2 = 3/4 · 2/1 = 6/4 = 3/2

Potens og kvadratrod

aⁿ = a · a · a … (n gange)
2³ = 2 · 2 · 2 = 8
a⁰ = 1, når a ≠ 0
5⁰ = 1
aⁿ · aᵐ = aⁿ⁺ᵐ
2³ · 2² = 2⁵ = 32
aⁿ / aᵐ = aⁿ⁻ᵐ, når a ≠ 0
2⁵ / 2² = 2³ = 8
(aⁿ)ᵐ = aⁿ·ᵐ
(2²)³ = 2⁶ = 64
√(a · b) = √a · √b, når a og b er 0 eller positive
√36 = √(4 · 9) = 2 · 3 = 6

Negative tal

Plus og minus:

  • To minusser bliver til plus: 5 − (−3) = 5 + 3 = 8
  • Plus og minus = minus: 5 + (−3) = 5 − 3 = 2

Gange og dividere:

  • Plus · plus = plus
  • Minus · minus = plus
  • Plus · minus = minus
Eksempel

(−3) · (−4) = 12

(−6) · 2 = −12

−10 / (−5) = 2

7 − (−2) = 9
